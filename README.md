# 🎬 CineMatch - Movie Recommendation System

CineMatch is a content-based movie recommendation system built using Python and Machine Learning. It recommends movies based on the similarity between their descriptions, genres, and keywords.

## 🚀 Features

- Select a movie from the available dataset
- Get 5 similar movie recommendations
- Uses TF-IDF for text feature extraction
- Uses cosine-based nearest-neighbor search
- Interactive web interface using Streamlit

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- TF-IDF
- Nearest Neighbors
